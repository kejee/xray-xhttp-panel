# 🚀 Xray-XHTTP-Panel 纯 IP 极简安全版

这是一个专为“纯 IP 直连”设计的极简、高效、高安全的 Xray 节点一键部署脚本。
采用目前轻量且强大的抗封锁组合：**VLESS + Reality + XHTTP**，内置一键复制/导入节点的 Web 管理面板。

## ✨ 核心特性

* **🛡️ 极致隐蔽**：无需配置域名与签发证书，基于 Reality 的 TLS 伪装 + XHTTP 底层传输混淆，防探测能力极强。
* **🎲 自由端口修改**：支持在网页面板随时、动态修改节点运行端口，摆脱端口被随机阻断或扫描的困扰。*（⚠️ 安全提醒：修改端口后，请务必确保您的云服务器防火墙已放行了对应的端口，强烈推荐直接放行 50000–65535 范围，否则将导致节点断连！）*
* **📊 实时流量与多设备在线监控 (0 额外公网出站流量)**：
  * **精准双层解耦**：账号层 100% 依赖 Xray 原生 Stats API，按 UUID 独立记账；物理层 100% 基于 Linux 内核 Socket（`ss -nt`），秒级反映物理连接。
  * **持久化记账**：独立持久化记账（`stats.db`），服务器开关机与 Xray 重启历史累计用量永不归零。
  * **动态速率与连接识别**：实时计算总下行/上行速率与各用户当前速率；动态展示当前连入的活跃设备 IP 列表。
  * **标准订阅协议**：支持为小火箭 / Clash / v2rayN 等客户端注入 `Subscription-Userinfo` 响应头，客户端界面直接展示流量用量进度条。
  * **单用户流量清零**：前端每 3 秒异步局部刷新，支持在面板上一键重置指定用户的累计流量。
  * **弹性流量池与自定义限额**：默认不设限额（无限流量模式），清晰展示本月总消耗；支持在管理面板随时自定义设置月度流量限制（GB，设为 0 即为不限），超额自动预警并提供视觉化进度条。
* **📦 全量数据无损备份与一键迁移 (零改动复活)**：
  * **全量配置导出**：网页端支持一键导出 `xray_full_backup.json`，完整打包 **所有用户列表、Reality 密钥对（私钥/公钥）、ShortId、节点运行端口及传输混淆路径**。
  * **跨机无感迁移**：灾难恢复或更换 VPS 后直接导入该全量备份，Xray 底层密钥和端口即刻同步还原，**所有原客户端无需重新扫码、无需更改订阅，直接无缝联网**！
  * **智能兼容恢复**：网页导入自动识别全量备份、原生 Xray `config.json` 或旧版纯用户列表；全新部署时将备份文件放置在脚本同目录亦可全自动静默恢复。
* **🧠 智能状态记忆**：支持随时**重复运行安装脚本**！程序会自动继承和提取原有的密钥、用户数据和运行端口，覆盖升级永不断连。
* **⚡ 内核级加速**：部署完成后自动检测并配置 Linux 原生 BBR 拥塞控制算法，大幅拔高跨国带宽跑速。
* **🔐 隐私去敏感化**：绝不硬编码任何默认密码。每次安装动态生成专属随机强密码与 Flask 签名密钥，杜绝全网盲扫爆破。

## 🛠️ 环境要求

* **系统支持**：Ubuntu 20.04+ / Debian 11+
* **权限要求**：`root` 用户权限
* **环境净度**：建议在未安装过其他 Web 面板（如 x-ui, 宝塔）的纯净 VPS 环境上运行。

## 🚀 快速安装

SSH 登录到您的服务器，切换至 root 权限，然后执行以下命令即可一键部署：

```bash
wget -O install.sh https://raw.githubusercontent.com/kejee/xray-xhttp-panel/main/install.sh

sudo bash install.sh
```

> **💡 注意：** 安装成功后，终端会打印出包含面板登录地址、动态随机密码以及初始端口信息的汇总表格，请务必截图或保存！

---

## ⚙️ 进阶用法 (命令行指定端口)

脚本支持极高的弹性配置。如果您不想使用随机生成的端口，可以在执行脚本时直接指定参数：

```bash
# 语法：sudo bash install.sh [面板管理端口] [Xray节点端口]
sudo bash install.sh 56003 54321
```

*执行上述命令后，Web 管理面板将固定运行在 `56003` 端口，Xray 节点将运行在 `54321` 端口。*

---

## ⚠️ 防火墙重要提醒 (必看)

安装完成后，请**务必**前往您的云服务器后台控制台（如 DigitalOcean, AWS, 阿里云, 腾讯云, Vultr），在**安全组 / Firewall (入站规则 / Inbound rules)** 中放行以下 TCP 端口，否则将导致面板无法打开、节点无法连接：

1. **`22`** (SSH 远程连接端口，必须保留)
2. **您的面板端口** (脚本安装结束时打印的 PANEL_PORT)
3. **您的节点端口** (脚本安装结束时打印的 XRAY_PORT，或您后续在网页面板中修改的新端口)

*🛡️ **黄金折中实践：** 强烈建议直接在云服务器防火墙中添加一条规则：放行 **`TCP 50000-65535`** 的端口范围。这样以后在网页面板里随时修改节点端口，**无需再反复登录云平台控制台配置防火墙**，且兼顾了低位核心端口的安全。*

## 🔧 常用维护命令

面板服务和底层 Xray 核心均已注册为 Linux 系统级守护进程（Systemd），异常会自动重启。在日常运维或排查错误时，以下常用命令能极大地提升您的效率：

### 1. 服务控制命令

```bash
# 重启 Web 管理面板 (手动修改了后台 app.py 代码后需执行)
sudo systemctl restart xray-panel

# 重启 Xray 核心 (手动修改或覆盖了 config.json 后需执行)
sudo systemctl restart xray

# 停止 / 开启 Xray 节点服务
sudo systemctl stop xray
sudo systemctl start xray

# 查看服务当前详细运行状态与运行时间
sudo systemctl status xray-panel
sudo systemctl status xray
```

### 2. 核心配置校验 (核心推荐)

如果您在终端手动修改过 Xray 的底层配置文件，请**务必**在执行重启命令前，使用 Xray 内置的测试参数校验 JSON 语法是否合法。这能 100% 避免因逗号、括号缺失导致服务挂掉的情况：

```bash
# 校验配置文件语法与路由逻辑
xray run -test -config /etc/xray/config.json
```

* **验证通过**：如果终端最后输出 `Configuration OK`，代表配置无误，可放心执行重启命令。
* **验证失败**：如果报错，会精确提示具体的错误原因及对应的 JSON 行号，根据提示修复即可。

### 3. 日志实时排查

当手机客户端提示连不上、或者浏览器打不开面板时，请通过以下命令查看实时输出日志，所有连接错误及系统报错一目了然：

```bash
# 实时查看 Web 管理面板的运行与请求日志 (按 Ctrl+C 退出)
sudo journalctl -u xray-panel -f

# 实时查看 Xray 核心的客户端连接、指纹握手日志 (按 Ctrl+C 退出)
sudo journalctl -u xray -f
```
